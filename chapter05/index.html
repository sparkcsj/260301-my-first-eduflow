    처음 만나는 오렌지3 — 클릭만으로 데이터 분석?!¶

    🎯 이 장의 학습 목표¶

    • 오렌지3의 화면 구성(캔버스, 위젯, 연결선)을 설명할 수 있다
    • 샘플 데이터셋을 불러와 테이블로 확인할 수 있다
    • 예상 학습 시간: 약 10분

    📚 미리 알아야 할 것¶

    • 4장에서 오렌지3를 설치했어요. 아직 안 했다면 4장을 먼저 확인해 주세요!

    📚 핵심 개념¶

    개념: 위젯과 연결선¶

    1. 비유로 시작: 오렌지3는 마치 레고 블록 조립과 같아요. 블록(위젯)을 꺼내서 판(캔버스) 위에 놓고, 블록끼리 연결하면 데이터 분석이 완성됩니다! 🧱

    2. 정확한 정의

    3. 위젯: 하나의 기능을 담당하는 블록 (데이터 불러오기, 표 보기 등)
    4. 캔버스: 위젯을 배치하는 넓은 작업 공간

    5. 연결선: 위젯 사이를 잇는 선. 데이터가 이 선을 따라 흘러갑니다

    6. 한눈에 보기

    flowchart LR A["📂 File\n(데이터 불러오기)"] -->|연결선: 데이터 흐름| B["📋 Data Table\n(데이터 보기)"]

    💡 잠깐! 위젯 = 기능 블록, 연결선 = 데이터 흐름. 이 두 가지만 기억하면 돼요!

    🔨 따라하기¶

    Step 1: File 위젯으로 데이터 불러오기¶

    1. 오렌지3를 실행하세요
    2. 왼쪽 위젯 목록에서 Data → File을 캔버스에 드래그하세요
    3. File 위젯을 더블클릭하면 설정 창이 열려요
    4. 기본으로 iris(아이리스 꽃 데이터)가 선택되어 있어요 → 그대로 두세요!

    ✅ 체크포인트: File 위젯 아래에 "150 instances, 5 variables"라고 보이면 성공!

    Step 2: Data Table로 데이터 확인하기¶

    1. 왼쪽 목록에서 Data → Data Table을 캔버스에 드래그하세요
    2. File 위젯의 오른쪽 반원에서 Data Table의 왼쪽 반원으로 마우스를 끌어 연결하세요
    3. Data Table을 더블클릭하면 — 🎉 표 형태의 데이터가 눈앞에!

    ✅ 체크포인트: 꽃받침 길이, 너비 등 숫자 데이터가 150줄 보이면 완벽해요!

    ⚠️ 주의할 점¶

    • 연결선이 안 그려져요: 위젯의 반원(동그란 점) 위에서 드래그를 시작해야 해요. 위젯 몸통이 아니라 가장자리 점을 노려주세요!
    • 위젯을 못 찾겠어요: 왼쪽 패널 상단의 검색창에 "File"이라고 입력하면 바로 나옵니다

    ✅ 점검하기¶

    1. 오렌지3에서 '위젯'이란 무엇인가요?

    정답 확인하나의 기능(데이터 불러오기, 표 보기 등)을 담당하는 블록입니다.

    2. 위젯 사이의 연결선은 어떤 역할을 하나요?

    정답 확인데이터가 흘러가는 통로 역할을 합니다. 연결선을 따라 데이터가 다음 위젯으로 전달돼요.

    3. 코드를 한 줄이라도 작성했나요?

    정답 확인아니요! 클릭과 드래그만으로 데이터를 불러오고 확인했어요. 이것이 오렌지3의 매력입니다. 😊

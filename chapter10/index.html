    데이터 불러오기 — 판다스와 첫 인사¶

    🎯 이 장의 학습 목표¶

    • pandas 라이브러리를 import하고 CSV 파일을 불러올 수 있다
    • head(), shape으로 데이터를 탐색할 수 있다

    예상 학습 시간: 약 10분

    📚 미리 알아야 할 것¶

    • 9장에서 변수에 값을 저장하고 print()로 출력하는 법을 배웠어요

    📚 핵심 개념¶

    개념: 판다스(pandas) 라이브러리¶

    1. 비유로 시작: 판다스는 마치 미리 만들어진 도구 상자 🧰와 같아요. 데이터를 다루는 도구가 잔뜩 들어 있어서, 꺼내 쓰기만 하면 됩니다.

    2. 정확한 정의: pandas는 파이썬에서 표 형태의 데이터를 다루는 라이브러리예요. 불러온 데이터는 DataFrame이라는 표로 저장됩니다.

    3. 오렌지3과 비교하면? 오렌지3에서 File 위젯 → Data Table 위젯으로 연결했던 것, 기억나시죠? 파이썬에서는 코드 3줄로 같은 일을 합니다!

    flowchart LR A["🍊 오렌지3\nFile → Data Table\n(드래그 & 클릭)"] --- C["같은 결과!"] B["🐍 파이썬\nimport → read_csv → head\n(코드 3줄)"] --- C

    🔨 따라하기¶

    Step 1: 데이터 불러와서 확인하기¶

    코드: 

    import pandas as pd  # 도구 상자 꺼내기

df = pd.read_csv("https://raw.githubusercontent.com/datasets/iris/master/data/iris.csv")

print(df.head())   # 처음 5줄 보기
print(df.shape)    # (행 수, 열 수)

    실행 결과: 

       sepal_length  sepal_width  petal_length  petal_width species
0           5.1          3.5           1.4          0.2  setosa
1           4.9          3.0           1.4          0.2  setosa
2           4.7          3.2           1.3          0.2  setosa
3           4.6          3.1           1.5          0.2  setosa
4           5.0          3.6           1.4          0.2  setosa
(150, 5)

    💡 잠깐! (150, 5)는 "150행, 5열"이라는 뜻이에요. 오렌지3 Data Table에서 보았던 그 표와 똑같은 데이터랍니다!

    📝 전체 코드¶

    import pandas as pd
df = pd.read_csv("https://raw.githubusercontent.com/datasets/iris/master/data/iris.csv")
print(df.head())
print(df.shape)

    ⚠️ 주의할 점¶

    • pandas가 없다는 에러가 나면? → 셀에 !pip install pandas를 먼저 실행하세요
    • pd는 별명이에요: import pandas as pd에서 as pd는 매번 긴 이름 대신 짧게 쓰려는 약속입니다

    ✅ 점검하기¶

    1. df.head()는 데이터의 몇 줄을 보여줄까요?
    정답 확인처음 5줄을 보여줍니다. head(3)처럼 숫자를 넣으면 3줄만 볼 수도 있어요.
    1. df.shape의 결과가 (150, 5)일 때, 150과 5는 각각 무엇일까요?
    정답 확인150은 행(데이터 수), 5는 열(특성 수)입니다.

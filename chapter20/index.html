    💡 왜 이걸 배우나요?¶

    지금까지 우리는 남이 만든 데이터로 분석하는 법을 배웠어요. 하지만 진정한 데이터 분석가는 이 질문을 할 줄 알아야 해요:

    "내가 궁금한 것을 어떻게 데이터로 답할 수 있을까?"

    이것이 최종 프로젝트의 핵심입니다.

    당신이 선택한 주제에 대해 스스로 문제를 정의하고, 직접 수집하고, 분석하고, 세상에 전하는 경험을 하게 돼요. 이 과정이 곧 '진정한 데이터 분석 업무'와 똑같은 경험이에요.

    마치 백지에 자신의 그림을 완성하는 화가처럼, 당신도 자신의 데이터 이야기를 완성할 준비가 된 것입니다! 🎨

    📊 핵심 개념¶

    개념 1: 데이터 분석 프로젝트의 6단계 구조¶

    데이터 분석은 정해진 순서대로 진행되는 여행이라고 생각해 봅시다. 관광지 방문 순서가 정해져 있듯이, 분석도 단계가 있어요.

    6단계 프로세스:

    📍 단계 1: 주제 정의 (Why & What?)
    ↓
📊 단계 2: 데이터 수집 (Where & How?)
    ↓
🧹 단계 3: 데이터 정제 (Clean data)
    ↓
🔍 단계 4: 탐색적 분석 (Exploration)
    ↓
📈 단계 5: 시각화 및 인사이트 (Story)
    ↓
🎤 단계 6: 스토리텔링 발표 (Tell)

    각 단계를 건너뛰면 안 돼요. 부실한 수집 → 부실한 정제 → 신뢰할 수 없는 분석이 되기 때문입니다.

    예시로 보면:

    당신이 "우리 학교 학생들이 얼마나 스트레스를 받고 있을까?"라는 주제를 선정했다면:

    • 단계 1: 스트레스 수준을 어떻게 측정할까? (주관적 설문? 수면시간? 카페인 섭취량?)
    • 단계 2: 누구에게 물어볼까? (전체 학생? 특정 학년? 성별별 분석?)
    • 단계 3: 불완전한 답변 제거, 이상치 확인
    • 단계 4: 학년별로 다를까? 시간대별로 변할까?
    • 단계 5: 그 결과를 어떤 그래프로 보여줄까?
    • 단계 6: "우리 학교 3학년이 가장 스트레스가 높으며, 그 이유는..."

    💡 핵심: 각 단계는 다음 단계의 기초가 돼요. 서두르지 말고 정성껏 진행하세요!

    개념 2: 좋은 주제의 3가지 특징¶

    모든 주제가 좋은 분석 대상은 아니에요. 좋은 프로젝트 주제는 다음 조건을 만족해야 해요:

    특징 1: 진짜 궁금해야 한다 (Genuine curiosity)

    "점수를 위해 하는 분석"은 흥미로운 결과가 나올 수 없어요. 당신이 정말로 "왜?", "어쨌?", "그럼 이건?" 하고 궁금해할 주제여야 해요.

    특징 2: 데이터로 답할 수 있어야 한다 (Data-driven answerable)

    "아름다움이란 무엇인가?"는 철학 질문이지 데이터 분석 문제가 아니에요. 반면 "패션 인스타그래머의 게시물 중 어떤 색상이 더 많은 좋아요를 받을까?"는 데이터로 답할 수 있어요.

    특징 3: 데이터를 구할 수 있어야 한다 (Data availability)

    좋은 질문이어도 데이터가 없으면 할 수 없어요. 공개 데이터, 설문조사, 크롤링 등으로 실제로 구할 수 있는 주제여야 해요.

    좋은 주제 vs 부적절한 주제:

    • ✅ "SNS 팔로워가 많은 유튜버와 조회수의 관계는?" → 공개 데이터 있음
    • ✅ "우리 집 전기료가 계절마다 어떻게 변할까?" → 직접 수집 가능
    • ✅ "영화 평점과 영화 개봉 후 시간은 상관이 있을까?" → 크롤링 가능
    • ❌ "날씨가 기분에 미치는 영향" → '기분'을 객관적으로 측정할 데이터가?
    • ❌ "우리 집 강아지 이름과 성격" → 하나의 사례일 뿐, 일반화 불가
    • ❌ "미국 비밀 프로젝트의 실제 규모" → 공개되지 않은 데이터

    💡 팁: 주제가 정해지지 않았다면, "평소에 궁금했던 것 중 수치로 나타낼 수 있는 것"부터 생각해 보세요!

    개념 3: 데이터 스토리텔링 — 숫자를 이야기로¶

    분석은 완료했는데 발표가 지루하다면? 그건 스토리가 없기 때문이에요.

    데이터 스토리텔링이란 분석 결과를 단순한 숫자가 아니라 의미 있는 이야기로 전달하는 기술입니다.

    스토리텔링 구조 (흔히 쓰이는 형식):

    1️⃣ 상황 설정 (Context)
   "요즘 온라인 쇼핑이 급증했어요"

2️⃣ 문제 제기 (Conflict)
   "하지만 배송 지연 때문에 고객 불만도 늘었어요"

3️⃣ 데이터 제시 (Data)
   "실제로 저희는 지난 3개월간 배송 시간 데이터를 수집했어요"
   [그래프 보여주기]

4️⃣ 인사이트 (Insight)
   "분석 결과, 주중 주문이 주말 주문보다 24시간 늦게 도착했어요"

5️⃣ 결론 & 제안 (Conclusion)
   "따라서 주중 배송 인력을 20% 증원하면 이 문제를 해결할 수 있습니다"

    반대의 예 (스토리가 없는 발표):

    • "평균은 3.2입니다. 표준편차는 0.8입니다. 다음 슬라이드..."

    이렇게 숫자만 나열하면 청중이 따분해요.

    좋은 스토리텔링 예:

    • "학교 매점에서 판매하는 음료 중 가장 인기 있는 것이 뭘까요? 저는 이 질문이 궁금했어요. 한 달간 판매량을 기록했고, 놀라운 사실을 발견했어요. [그래프] 여름인데도 아이스 음료가 핫 음료보다 못 팔렸어요! 왜 그럴까? 알고 보니..."

    💡 핵심: 데이터는 증거지, 주인공이 아니에요. 당신의 질문과 발견이 주인공입니다!

    개념 4: 오렌지3 vs 파이썬 — 언제 뭘 쓸까?¶

    지금까지 두 도구를 배웠어요. 언제 뭘 쓸까요?

    오렌지3를 쓰면 좋을 때:

    • 빠르게 시각적으로 탐색하고 싶을 때
    • 머신러닝 모델을 한두 번에 만들고 싶을 때
    • 코딩 경험이 부족할 때
    • 팀원과 빠르게 결과를 공유하고 싶을 때

    파이썬을 쓰면 좋을 때:

    • 정밀하게 커스터마이징하고 싶을 때
    • 복잡한 데이터 정제가 필요할 때
    • 여러 시각화 옵션을 시도하고 싶을 때
    • 재현 가능한 코드로 남기고 싶을 때

    최종 프로젝트의 전략:

    → 오렌지3로 빠르게 탐색한 후, 파이썬으로 최종 시각화 완성하기

    이렇게 두 도구를 조합하면 가장 효율적이에요!

    목표: 깨끗하고 분석 가능한 데이터로 만들기

    import pandas as pd
import numpy as np

# 1단계: 데이터 로드
df = pd.read_csv('my_data.csv')

# 2단계: 기본 정보 확인
print(df.head())           # 처음 5행 보기
print(df.info())           # 자료형, 결측치 확인
print(df.describe())       # 기초 통계

# 3단계: 결측치 처리
print(df.isnull().sum())   # 결측치 개수 확인
df = df.dropna()           # 결측치 있는 행 제거

# 4단계: 이상치 확인 (숫자 범위 벗어난 것)
# 예: 성적은 0-100이어야 함
df = df[(df['성적'] >= 0) & (df['성적'] <= 100)]

# 5단계: 자료형 변환
df['사용시간'] = pd.to_numeric(df['사용시간'], errors='coerce')

# 6단계: 정제 완료 데이터 저장
df.to_csv('cleaned_data.csv', index=False)
print(f"정제 완료! {len(df)}개 행 남음")

    Step 4: 기초 통계와 그룹별 분석¶

    목표: 데이터의 기본 특징 파악하기

    파이썬 코드:

    import pandas as pd
import numpy as np

df = pd.read_csv('cleaned_data.csv')

# 1단계: 기초 통계
print("=== 기초 통계 ===")
print(f"평균 사용시간: {df['사용시간'].mean():.2f}시간")
print(f"최대값: {df['사용시간'].max()}시간")
print(f"최소값: {df['사용시간'].min()}시간")
print(f"표준편차: {df['사용시간'].std():.2f}")

# 2단계: 상관관계 계산
print("\n=== 상관관계 ===")
correlation = df['사용시간'].corr(df['성적'])
print(f"사용시간과 성적의 상관계수: {correlation:.3f}")

# 3단계: 그룹별 분석
print("\n=== 성별별 분석 ===")
grouped = df.groupby('성별').agg({
    '사용시간': 'mean',
    '성적': 'mean',
    '성별': 'count'
})
grouped.columns = ['평균사용시간', '평균성적', '인원']
print(grouped)

    import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv('cleaned_data.csv')

plt.rcParams['font.family'] = 'DejaVu Sans'

fig, axes = plt.subplots(2, 2, figsize=(12, 10))
fig.suptitle('My Data Story: Smartphone Usage & Academic Performance', 
             fontsize=16, fontweight='bold')

# 그래프 1: 산점도 (사용시간 vs 성적)
axes[0, 0].scatter(df['사용시간'], df['성적'], alpha=0.6, s=100, color='steelblue')
axes[0, 0].set_xlabel('Daily Smartphone Usage (hours)', fontsize=11)
axes[0, 0].set_ylabel('Test Score (out of 100)', fontsize=11)
axes[0, 0].set_title('Relationship: Usage vs Score', fontweight='bold')
axes[0, 0].grid(True, alpha=0.3)

# 추세선 추가
z = np.polyfit(df['사용시간'], df['성적'], 1)
p = np.poly1d(z)
axes[0, 0].plot(df['사용시간'].sort_values(), 
                p(df['사용시간'].sort_values()), 
                "r--", linewidth=2, label='Trend')
axes[0, 0].legend()

# 그래프 2: 히스토그램 (사용시간 분포)
axes[0, 1].hist(df['사용시간'], bins=10, color='coral', edgecolor='black', alpha=0.7)
axes[0, 1].set_xlabel('Daily Usage (hours)', fontsize=11)
axes[0, 1].set_ylabel('Number of Students', fontsize=11)
axes[0, 1].set_title('Distribution of Usage Time', fontweight='bold')
axes[0, 1].grid(True, alpha=0.3, axis='y')

# 그래프 3: 박스플롯 (성별별 성적)
df.boxplot(column='성적', by='성별', ax=axes[1, 0])
axes[1, 0].set_xlabel('Gender', fontsize=11)
axes[1, 0].set_ylabel('Test Score', fontsize=11)
axes[1, 0].set_title('Score Distribution by Gender', fontweight='bold')
plt.sca(axes[1, 0])
plt.xticks([1, 2], ['Female', 'Male'])

# 그래프 4: 바차트 (그룹별 평균)
group_means = df.groupby('성별')[['사용시간', '성적']].mean()
x = np.arange(len(group_means))
width = 0.35

ax4 = axes[1, 1]
bar1 = ax4.bar(x - width/2, group_means['사용시간'], width, 
               label='Avg Usage (hours)', color='skyblue')
ax4_twin = ax4.twinx()
bar2 = ax4_twin.bar(x + width/2, group_means['성적'], width, 
                    label='Avg Score', color='orange')

ax4.set_xlabel('Gender', fontsize=11)
ax4.set_ylabel('Usage (hours)', fontsize=11, color='skyblue')
ax4_twin.set_ylabel('Score (points)', fontsize=11, color='orange')
ax4.set_title('Average Comparison by Gender', fontweight='bold')
ax4.set_xticks(x)
ax4.set_xticklabels(['Female', 'Male'])
ax4.legend(loc='upper left')
ax4_twin.legend(loc='upper right')

plt.tight_layout()
plt.savefig('my_analysis_visualization.png', dpi=300, bbox_inches='tight')
print("✅ 시각화 완료! 'my_analysis_visualization.png' 저장됨")
plt.show()

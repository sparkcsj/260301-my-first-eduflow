    데이터는 어디에나 있다 — 실생활 속 데이터 발견하기¶

    🎯 이 장의 학습 목표¶

    • 일상에서 데이터가 수집되는 상황을 3가지 이상 찾을 수 있다
    • 정형 데이터와 비정형 데이터를 사례로 구분할 수 있다
    • 예상 학습 시간: 약 10분

    📚 미리 알아야 할 것¶

    • 1장에서 데이터과학이 무엇인지 간단히 살펴봤어요. 이번엔 그 재료인 데이터에 집중합니다!

    📚 핵심 개념¶

    개념: 데이터 📦¶

    1. 비유로 시작

    데이터는 마치 요리 재료와 같아요. 당근, 양파, 고기 — 그 자체론 요리가 아니지만, 모이면 맛있는 이야기(결과)를 만들어내죠.

    2. 정확한 정의

    데이터란 어떤 사실을 기록한 것입니다. 숫자뿐 아니라 글, 사진, 음성도 모두 데이터예요.

    3. 예시로 확인 — '이것도 데이터야?' 🤔

    • 오늘 스마트폰 스크린타임 3시간 42분 → 숫자 데이터!
    • 친구가 보낸 카톡 메시지 → 텍스트 데이터!
    • 인스타그램에 올린 셀카 사진 → 이미지 데이터!

    💡 잠깐! 우리는 하루에도 수백 개의 데이터를 만들고 있어요. 의식하지 못했을 뿐이에요!

    정형 데이터 vs 비정형 데이터¶

    graph LR A["🗂️ 데이터"] --> B["📊 정형 데이터<br/>엑셀 표처럼 깔끔하게<br/>행과 열로 정리된 것<br/>(예: 성적표, 출석부)"] A --> C["📝 비정형 데이터<br/>정해진 틀 없이<br/>자유로운 형태<br/>(예: SNS 댓글, 사진)"]
    • 정형 데이터: 학교 성적표처럼 칸칸이 정리된 데이터
    • 비정형 데이터: 유튜브 댓글처럼 형태가 자유로운 데이터

    🔨 따라하기¶

    Step 1: 파이썬으로 정형 데이터 맛보기¶

    # 급식 인기 메뉴 투표 결과 (정형 데이터)
menu = {"치킨": 15, "피자": 12, "떡볶이": 20}
for name, votes in menu.items():
    print(f"{name}: {'⭐' * (votes // 5)} ({votes}표)")

    실행 결과: 

    치킨: ⭐⭐⭐ (15표)
피자: ⭐⭐ (12표)
떡볶이: ⭐⭐⭐⭐ (20표)

    ✅ 체크포인트: 별이 표 수에 비례해서 출력되면 성공이에요!

    📝 전체 코드¶

    menu = {"치킨": 15, "피자": 12, "떡볶이": 20}
for name, votes in menu.items():
    print(f"{name}: {'⭐' * (votes // 5)} ({votes}표)")

    ⚠️ 주의할 점¶

    • "데이터 = 숫자"라고 생각하지 마세요! 사진, 글, 음성 모두 데이터입니다.
    • 정형·비정형 구분이 헷갈리면 "엑셀 표에 넣을 수 있나?" 를 떠올려보세요. 넣을 수 있으면 정형!

    ✅ 점검하기¶

    1. 다음 중 비정형 데이터는? - (A) 출석부 (B) 인스타그램 댓글 (C) 시험 성적표

    정답 확인✅ (B) 인스타그램 댓글 — 정해진 형식 없이 자유롭게 쓰이니까요!

    2. "데이터"를 자신의 말로 한 문장으로 정의해보세요.

    예시 답변✅ "데이터란 세상의 사실을 기록한 모든 것이다." 비슷한 의미라면 정답이에요! 👏

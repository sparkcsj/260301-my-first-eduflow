    왜 데이터과학을 배워야 할까? — 이 책의 사용법¶

    🎯 이 장의 학습 목표¶

    • 데이터과학이 일상 속 어디에 있는지 설명할 수 있다
    • 이 교재의 학습 로드맵을 이해하고 나만의 계획을 세울 수 있다
    • "나도 할 수 있다"는 학습 동기를 갖고 출발할 수 있다

    예상 학습 시간: 약 10분

    📚 미리 알아야 할 것¶

    첫 번째 장이니까, 아무것도 몰라도 괜찮아요! 😊

    📚 핵심 개념¶

    개념: 데이터과학(Data Science)¶

    1. 비유로 시작해 볼게요

    🍳 데이터과학은 마치 요리와 같아요. 냉장고 속 재료(데이터)를 꺼내서, 레시피(분석 방법)에 따라 조리하면, 맛있는 요리(유용한 정보)가 완성되는 거예요.

    2. 정확한 정의

    데이터과학이란, 세상에 흩어진 데이터를 모으고 → 정리하고 → 분석해서 → 의미 있는 답을 찾아내는 과정이에요.

    3. 예시로 확인 — 이미 여러분의 하루 속에 있어요!

    • 🎵 스포티파이·유튜브 뮤직: "이 노래 좋아하시죠?" → 내 취향 데이터를 분석한 결과
    • 🌦️ 날씨 앱: 내일 비 올 확률 80% → 수십만 개 기상 데이터를 분석한 결과
    • 🛒 쿠팡·배민 추천: "이 상품 어때요?" → 구매 패턴 데이터를 분석한 결과

    💡 잠깐! 데이터과학은 먼 미래의 기술이 아니에요. 오늘 아침 여러분이 본 뉴스 피드도 데이터과학의 결과물이랍니다.

    🔨 따라하기¶

    Step 1: 나의 데이터과학 관심도 자가진단¶

    아래 코드를 복사해서 실행해 보세요. 간단한 질문에 답하면 나의 관심도를 알려줘요!

    코드: 

    # 나의 데이터과학 관심도 자가진단
print("=== 데이터과학 관심도 퀴즈 ===\n")

questions = [
    "유튜브 추천 영상이 어떻게 뜨는지 궁금한 적 있다 (1:예 / 0:아니오): ",
    "엑셀이나 숫자 다루는 걸 해본 적 있다 (1:예 / 0:아니오): ",
    "AI·빅데이터 뉴스를 보면 흥미가 생긴다 (1:예 / 0:아니오): ",
]

score = 0
for q in questions:
    answer = int(input(q))
    score += answer

print(f"\n당신의 관심도 점수: {score}/3")
if score >= 2:
    print("🔥 데이터과학에 이미 관심이 높으시네요! 잘 오셨어요!")
elif score == 1:
    print("👍 좋은 출발이에요! 이 책과 함께 흥미가 더 커질 거예요!")
else:
    print("😊 괜찮아요! 아무것도 몰라도 이 책이 안내해 드릴게요!")

    실행 결과 (예시):

    🗺️ 이 교재의 로드맵¶

    flowchart LR A["📖 1권\n개념 & 흥미\n(지금 여기!)"] --> B["💻 2권\n실습 & 체험"] A --- A1["데이터과학이란?"] A --- A2["핵심 개념 이해"] B --- B1["파이썬 실습"] B --- B2["미니 프로젝트"]
    • 1권: 코딩 없이도 이해할 수 있는 개념과 재미있는 사례
    • 2권: 직접 코드를 치며 데이터를 만져보는 실습

    💪 코딩을 몰라도, 수학을 잘 못해도 전혀 괜찮아요. 이 책은 그런 분들을 위해 만들었습니다!

    ✅ 점검하기¶

    1. 데이터과학을 한 문장으로 설명한다면?

    정답 확인 데이터를 모아서 분석하고, 그 안에서 **의미 있는 정보를 찾아내는 과정**이에요.

    2. 일상 속 데이터과학 사례를 하나만 말해 본다면?

    정답 확인 유튜브 영상 추천, 날씨 예보, 쇼핑몰 상품 추천 등 — 어떤 것이든 정답이에요! 🎉

    3. 이 교재 1권과 2권의 차이는?

    정답 확인 **1권**은 개념과 흥미 위주, **2권**은 직접 코딩하며 체험하는 실습 위주입니다.

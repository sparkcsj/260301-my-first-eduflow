    15장. 다음 단계로 나아가기 — 데이터과학, 이제 시작이야! 🚀¶

    🎯 이 장의 학습 목표¶

    • 데이터과학을 더 공부할 무료 학습 자료를 알 수 있다
    • 인문·언어 × 데이터과학 융합 분야를 탐색할 수 있다
    • 나만의 다음 단계 계획을 세울 수 있다

    예상 학습 시간: 약 5분

    📚 핵심 개념¶

    개념: 학습 로드맵¶

    수업은 끝나지만, 여러분의 데이터과학 여정은 이제 시작이에요! 🎉

    다음 단계는 마치 게임의 월드맵과 같아요. 지금 튜토리얼 스테이지를 클리어한 것이고, 앞으로 흥미로운 스테이지가 기다리고 있어요.

    무료 학습 자료 (난이도순) - 🟢 Kaggle Learn (kaggle.com/learn) — 짧은 실습 코스, 영어지만 쉬움 - 🟡 파이썬 코딩도장 (dojang.io) — 한국어, 문법 심화 - 🔴 Coursera "Data Science 입문" — 체계적 강좌, 무료 청강 가능

    인문·언어 × 데이터과학 융합 분야 - 🗣️ 전산언어학: AI 번역, 챗봇의 핵심 기술 - 💬 감성 분석: SNS 텍스트에서 감정을 읽어내는 기술 - 📰 데이터 저널리즘: 데이터로 기사를 쓰는 새로운 보도 방식 - 📜 디지털인문학: 고전 문헌을 데이터로 분석하는 연구

    graph LR A["🎓 지금 여기!"] --> B["파이썬 심화"] A --> C["데이터 분석 프로젝트"] B --> D["전산언어학 / AI"] C --> E["데이터 저널리즘"] C --> F["디지털인문학"]

    🔨 따라하기¶

    Step 1: 나의 다음 단계 계획 세우기¶

    아래 코드를 실행하고, 빈칸을 자신의 답으로 바꿔보세요!

    # 나의 데이터과학 다음 단계 계획
my_plan = {
    "흥미로운 융합 분야": "감성 분석",      # 바꿔보세요!
    "도전할 학습 자료": "Kaggle Learn",     # 바꿔보세요!
    "만들고 싶은 프로젝트": "영화 리뷰 분석"  # 바꿔보세요!
}

print("🚀 나의 데이터과학 다음 단계")
for key, value in my_plan.items():
    print(f"  ✨ {key}: {value}")
print("\n데이터과학, 이제 시작이야! 화이팅! 💪")

    Chapter 18. 파이썬으로 그래프 그리기 — matplotlib 첫걸음¶

    🎯 이 장의 학습 목표¶

    • matplotlib 라이브러리를 import하고 기본 그래프를 만들 수 있습니다
    • 막대 그래프, 선 그래프, 산점도를 파이썬 코드로 직접 그릴 수 있습니다
    • 제목, 축 레이블, 색상, 범례 등으로 그래프를 꾸밀 수 있습니다
    • 오렌지3와 파이썬 matplotlib의 차이를 이해하고 각 도구를 언제 사용할지 판단할 수 있습니다

    예상 학습 시간: 약 2시간

    📚 미리 알아야 할 것¶

    지난 장들에서 배운 내용을 잠깐 떠올려보세요.

    • 변수와 리스트: month = [1, 2, 3, 4, 5] 처럼 데이터를 저장하고 관리하기
    • 오렌지3에서의 시각화: 마우스 클릭으로 그래프를 그렸던 경험
    • 라이브러리 import: import를 사용해 필요한 도구를 불러오기

    이 정도면 충분해요. 모르는 부분이 있어도 이 장을 따라가면서 배울 수 있습니다! 😊

    💡 왜 이걸 배우나요?¶

    지금까지 오렌지3에서는 마우스 클릭으로 그래프를 만들었어요. 정말 편했죠! 하지만 프로그래밍 세계에서는 코드로 그래프를 만드는 것이 훨씬 강력합니다.

    상황을 상상해보세요: - 매달 새로운 판매 데이터가 들어옵니다. 매번 오렌지3를 열어서 마우스로 그래프를 만들까요? 아니면 코드 한 줄만 수정해서 자동으로 그래프를 업데이트할까요? - 100개의 다른 그래프가 필요합니다. 손으로 하나하나 만들까요? 아니면 반복문으로 한번에 만들까요?

    파이썬 matplotlib은 이런 상황에서 자동화, 정밀성, 반복성을 제공합니다. 또한 코드로 만든 그래프는 논문, 보고서, 웹사이트에 바로 넣을 수 있어요!

    📚 핵심 개념¶

    개념 1: matplotlib이 뭘까요?¶

    비유로 생각해봐요: - 종이에 그림을 그릴 때는 연필, 지우개, 색연필이 필요하죠. - 파이썬에서 그래프를 그릴 때도 matplotlib은 "디지털 연필" 같은 존재예요.

    정확한 정의: matplotlib은 파이썬의 시각화 라이브러리입니다. 숫자 데이터를 받아서 그래프, 차트, 플롯으로 변환해주는 도구예요.

    3줄 요약: 

    1. 데이터 준비 (리스트나 배열)
   ↓
2. matplotlib으로 명령 실행 (어떻게 그릴지 지시)
   ↓
3. 화면에 그래프 표시

    개념 2: pyplot이 뭔가요?¶

    matplotlib은 매우 큰 라이브러리예요. 하지만 우리는 보통 pyplot이라는 간단한 인터페이스를 사용합니다.

    import matplotlib.pyplot as plt

    이 한 줄이 무엇을 의미하는가: - matplotlib.pyplot = matplotlib이라는 큰 도구 상자에서 pyplot이라는 필수 도구 모음을 가져오기 - as plt = 앞으로 plt라고 짧게 부르기 (일종의 별명)

    쉽게 말해: 

    import matplotlib.pyplot as plt
= "matplotlib의 pyplot 도구를 plt라고 부르겠습니다"

    개념 3: 그래프 종류별 함수 이름 외우기¶

    matplotlib에서는 함수 이름만 봐도 뭘 그리는지 알 수 있어요. 영어처럼 읽으면 됩니다!

    plt.bar()     → bar = 막대 → 막대 그래프
plt.plot()    → plot = 그리기 → 선 그래프
plt.scatter() → scatter = 흩어지다 → 산점도

    개념 4: 그래프 완성의 3단계¶

    모든 그래프 만들기는 이 패턴을 따릅니다:

    1단계) 데이터 준비
      → x = [1, 2, 3, 4, 5]  (x축 데이터)
      → y = [10, 20, 15, 30, 25]  (y축 데이터)

2단계) 그래프 기본형 그리기
      → plt.bar(x, y)  또는 plt.plot(x, y)  또는 plt.scatter(x, y)

3단계) 꾸미기 (제목, 레이블, 색상 등)
      → plt.title("우리 매출 현황")
      → plt.xlabel("월")
      → plt.ylabel("판매량")

4단계) 화면에 보여주기
      → plt.show()

    💡 알아두세요: Step 1, 2, 3을 순서대로 하면 자동으로 한 그래프가 완성돼요. 마치 케이크를 만드는 것처럼요!

    🔨 따라하기¶

    이제 직접 해봐요. 차근차근 따라오시면 됩니다!

    Step 1: matplotlib 설치하고 import하기¶

    먼저 matplotlib이 설치되어 있는지 확인해요.

    터미널(또는 명령 프롬프트)에 이렇게 입력하세요:

    pip install matplotlib

    다음으로, 파이썬 파일을 만들고 이렇게 시작합니다:

    import matplotlib.pyplot as plt

    ✅ 체크포인트: 에러 메시지가 안 나오면 성공입니다!

    Step 2: 첫 번째 그래프 – 막대 그래프 (Bar Chart)¶

    시나리오: 여름방학 4주 동안 독서한 책의 권수를 그래프로 나타내고 싶어요.

    import matplotlib.pyplot as plt

# 1단계) 데이터 준비
weeks = [1, 2, 3, 4]              # x축: 주차
books = [3, 5, 4, 6]              # y축: 책 권수

# 2단계) 막대 그래프 그리기
plt.bar(weeks, books)

# 3단계) 꾸미기
plt.title("여름방학 독서량")       # 제목
plt.xlabel("주차")                 # x축 이름
plt.ylabel("책 권수")              # y축 이름

# 4단계) 화면에 보여주기
plt.show()

    이 코드를 실행하면: - 파이썬 창이 뜨고 바로 막대 그래프가 보여요 - 막대 4개가 높이 3, 5, 4, 6으로 그려집니다

    ✅ 체크포인트: 제목과 축 이름이 있는 막대 그래프가 보이나요? 맞으면 성공!

    Step 3: 두 번째 그래프 – 선 그래프 (Line Chart)¶

    시나리오: 한 달 동안의 매일 기온 변화를 추적하고 싶어요.

    import matplotlib.pyplot as plt

# 1단계) 데이터 준비
days = [1, 2, 3, 4, 5, 6, 7]
temperature = [20, 22, 21, 25, 24, 26, 23]

# 2단계) 선 그래프 그리기
plt.plot(days, temperature)

# 3단계) 꾸미기
plt.title("7월 기온 변화")
plt.xlabel("날짜")
plt.ylabel("기온(℃)")

# 4단계) 화면에 보여주기
plt.show()

    bar()와 plot()의 차이: - bar() = 막대로 연결 (이산적 데이터에 좋음) - plot() = 선으로 연결 (시간에 따른 변화에 좋음)

    ✅ 체크포인트: 점들이 선으로 연결되고 7개의 점이 보이나요?

    Step 4: 세 번째 그래프 – 산점도 (Scatter Plot)¶

    시나리오: 학생들의 공부 시간과 시험 성적의 관계를 알고 싶어요.

    import matplotlib.pyplot as plt

# 1단계) 데이터 준비
study_hours = [2, 3, 4, 5, 6, 7, 8]  # 공부 시간
scores = [60, 65, 70, 78, 82, 88, 92]  # 시험 성적

# 2단계) 산점도 그리기
plt.scatter(study_hours, scores)

# 3단계) 꾸미기
plt.title("공부 시간 vs 시험 성적")
plt.xlabel("공부 시간 (시간)")
plt.ylabel("시험 성적 (점)")

# 4단계) 화면에 보여주기
plt.show()

    산점도란: - 개별 데이터를 점(●)으로 표시합니다 - 두 변수 사이의 관계를 한눈에 볼 때 최고예요 - "공부를 많이 할수록 성적이 올라가나?" 같은 질문에 답해줍니다

    ✅ 체크포인트: 왼쪽 아래에서 오른쪽 위로 향하는 점들의 패턴이 보이나요?

    Step 5: 색상 추가해서 더 예쁘게 만들기¶

    같은 데이터를 여러 색으로 표현할 수 있어요:

    import matplotlib.pyplot as plt

weeks = [1, 2, 3, 4]
books = [3, 5, 4, 6]

# color 속성으로 색상 지정
plt.bar(weeks, books, color='#FF6B6B')  # 빨간색

# 또는 간단한 색상 이름 사용
# plt.bar(weeks, books, color='red')
# plt.bar(weeks, books, color='blue')
# plt.bar(weeks, books, color='green')

plt.title("여름방학 독서량")
plt.xlabel("주차")
plt.ylabel("책 권수")
plt.show()

    색상 지정 방법 3가지: 1. 이름으로: color='red', color='blue' 2. 축약형으로: color='r', color='b' 3. 16진수로: color='#FF6B6B' (더 정교한 색상)

    Step 6: 여러 그래프를 한번에 비교하기¶

    두 반의 성적을 나란히 보고 싶다면:

    import matplotlib.pyplot as plt

subjects = ['수학', '영어', '과학', '국어']
class_a = [85, 78, 90, 82]
class_b = [80, 85, 88, 79]

# 두 개의 막대를 나란히 그리기
x = [0, 1, 2, 3]
width = 0.35

plt.bar([i - width/2 for i in x], class_a, width=width, label='A반')
plt.bar([i + width/2 for i in x], class_b, width=width, label='B반')

plt.title("반별 과목 성적 비교")
plt.xlabel("과목")
plt.ylabel("성적")
plt.xticks(x, subjects)  # x축에 과목명 표시
plt.legend()  # 범례 표시

plt.show()

    ✅ 체크포인트: 각 과목별로 A반과 B반의 막대가 나란히 보이나요?

plt.xlabel("공부 시간")
plt.ylabel("시험 성적")
plt.show()
"""

    ⚠️ 자주 하는 실수¶

    실수 1: plt.show()를 빼먹음¶

    # ❌ 틀린 코드
import matplotlib.pyplot as plt
weeks = [1, 2, 3, 4]
books = [3, 5, 4, 6]
plt.bar(weeks, books)
plt.title("여름방학 독서량")
# 여기서 끝남 → 그래프가 안 보여요!

    왜 이런 일이 생기나요? - matplotlib은 명령을 받아도 plt.show() 없이는 화면에 띄우지 않아요 - 마치 "준비는 다 했는데 공연을 안 하는" 것처럼요

    이렇게 해결해요: 

    # ✅ 맞는 코드
import matplotlib.pyplot as plt
weeks = [1, 2, 3, 4]
books = [3, 5, 4, 6]
plt.bar(weeks, books)
plt.title("여름방학 독서량")
plt.show()  # ← 이 줄이 필수!

    실수 2: x, y 데이터의 길이가 다름¶

    # ❌ 틀린 코드
weeks = [1, 2, 3, 4]  # 4개
books = [3, 5, 4]     # 3개만 있음
plt.bar(weeks, books)  # 에러 발생!

    왜 이런 일이 생기나요? - x축에 4개의 점이 있는데 y값은 3개뿐이에요 - 파이썬은 "데이터가 안 맞는다"고 항의합니다

    이렇게 해결해요: 

    # ✅ 맞는 코드
weeks = [1, 2, 3, 4]
books = [3, 5, 4, 6]   # 길이를 맞춰요
plt.bar(weeks, books)

    실수 3: 한글 폰트가 깨짐¶

    # ❌ 한글 제목이 깨지는 경우
plt.title("여름방학 독서량")  # 네모박스나 물음표로 보임

    왜 이런 일이 생기나요? - matplotlib의 기본 폰트가 한글을 지원하지 않기 때문이에요

    이렇게 해결해요: 

    # ✅ 맞는 코드
import matplotlib.pyplot as plt
import matplotlib.font_manager as fm

# 한글 폰트 설정 (Mac/Linux)
plt.rcParams['font.family'] = 'DejaVu Sans'

# 또는 Windows의 경우
# plt.rcParams['font.family'] = 'Malgun Gothic'

weeks = [1, 2, 3, 4]
books = [3, 5, 4, 6]
plt.bar(weeks, books)
plt.title("여름방학 독서량")  # 이제 한글이 잘 보여요!
plt.show()

    ✅ 스스로 점검하기¶

    이 항목들을 모두 할 수 있으면 이 장을 완벽히 이해한 거예요! 체크해보세요.

    • import matplotlib.pyplot as plt 한 줄을 이해할 수 있다
    • 막대 그래프(plt.bar)를 직접 만들 수 있다
    • 선 그래프(plt.plot)와 산점도(plt.scatter)의 용도 차이를 설명할 수 있다
    • 그래프에 제목과 축 레이블을 추가할 수 있다
    • 색상을 지정해서 그래프를 꾸밀 수 있다
    • 자신의 데이터로 직접 그래프를 만들어본 경험이 있다

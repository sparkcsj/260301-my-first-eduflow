    Chapter 17. 오렌지3로 그래프 만들기 — 클릭 몇 번의 마법¶

    🎯 이 장의 학습 목표¶

    • 데이터를 보고 어떤 그래프가 가장 효과적인지 판단할 수 있어요
    • 오렌지3 워크플로우로 로드→분석→시각화의 전체 파이프라인을 완성할 수 있어요
    • 그래프를 보고 그 의미를 자신의 말로 설명할 수 있어요

    예상 학습 시간: 약 2시간

    📚 미리 알아야 할 것¶

    • 간단한 데이터 집합(예: 엑셀 파일, CSV 파일)을 준비할 수 있으면 좋아요

    💡 왜 이걸 배우나요?¶

    데이터를 손에 들면 뭐가 보일까요?

    숫자들의 나열일 뿐입니다. 📊

    "2020년 매출 1,200만 원, 2021년 1,500만 원, 2022년 1,800만 원..." — 이렇게만 들으면 따분하고, 무엇이 중요한지 한눈에 들어오지 않습니다.

    하지만 그래프로 표현하면? 📈

    마구마구 상승하는 선이 한 번에 "아, 매출이 계속 늘어나고 있구나!"라고 말해줍니다. 숫자보다 그림이 훨씬 강하고 빠르게 마음에 들어옵니다.

    이 장에서는 오렌지3라는 "데이터 시각화 도우미"를 사용해서 클릭 몇 번만으로 멋진 그래프를 만드는 법을 배워요. 파이썬 코드를 하나도 안 쳐도, 마우스로 위젯을 끌어다 놓으면 완성돼요. 마법처럼요! ✨

    이걸 배우면: - 데이터의 숨은 이야기를 시각적으로 발견할 수 있고 - 상사나 친구에게 설득력 있게 설명할 수 있으며 - 파이썬으로 만들어야 할 복잡한 코드를 먼저 맛보기할 수 있습니다

    📚 핵심 개념¶

    개념 1: 시각화 위젯의 역할 — "데이터를 말하는 방식 바꾸기"¶

    비유로 시작하면:

    같은 이야기도 전달 방식이 중요하잖아요. "서툰 말로 길게 설명"하는 것과 "핵심을 그림으로 보여주기"는 완전 다릅니다.

    정확한 정의:

    오렌지3의 시각화 위젯은 표 형태의 데이터를 그래프, 차트, 산점도 같은 그림으로 변환해주는 도구예요. 각 위젯은 다른 "이야기 전하기 방식"을 가지고 있습니다.

    예시로 확인:

    "학생 10명의 과목별 성적" 데이터가 있다고 해봐요. - 표로 보면: 숫자만 일렬로 나열 → 뭐가 어떻다는 건지 헷갈림 - 막대 그래프(Bar Plot)로 보면: 수학이 제일 높고, 영어가 낮다는 걸 한눈에 알 수 있음 ✨

    개념 2: Bar Plot — "그룹 간의 비교"¶

    언제 쓰나요? - 남/여 비교 - 부서별 판매량 비교 - 등급별 인원 수 비교

    시각적 특징: 옆으로 누운 막대 또는 세워진 막대로, 각 그룹의 크기를 비교합니다.

    막대 높이가 높을수록 = 그 그룹의 값이 크다

    개념 3: Line Plot — "시간에 따른 변화"¶

    언제 쓰나요? - 월별 판매 추이 - 일별 온도 변화 - 연도별 인구 성장

    시각적 특징: 시간순으로 연결된 점들이 선을 그려서, 흐름을 명확히 보여줍니다.

    선이 올라가면 = 증가 추세 📈
선이 내려가면 = 감소 추세 📉

    개념 4: Scatter Plot — "두 변수 간의 관계(상관관계)"¶

    언제 쓰나요? - 학생의 공부 시간과 성적의 관계 - 나이와 구매 금액의 관계 - 키와 몸무게의 관계

    시각적 특징: 점들이 흩어진 형태로, 패턴을 찾아냅니다.

    점들이 우상향 직선으로 흩어짐 = 양의 상관관계 (한쪽 ↑ → 다른 쪽도 ↑)
점들이 우하향 직선으로 흩어짐 = 음의 상관관계 (한쪽 ↑ → 다른 쪽은 ↓)
점들이 무작위로 흩어짐 = 관계 없음

    💡 잠깐! 이 세 가지 그래프가 "모든 그래프"인가요?

    아니에요! 오렌지3에는 수십 개의 시각화 위젯이 있어요. 하지만 이 3가지가 가장 자주 쓰이는 기본형이라서 먼저 배우는 거예요. 나중에 실무에서 "히스토그램", "박스 플롯", "히트맵" 같은 고급 시각화도 만나게 됩니다. 겁먹지 마세요! 😊

    🔨 따라하기¶

    이제 실제로 오렌지3를 켜서 워크플로우를 만들어봐요!

    실습 데이터 준비¶

    먼저 가상의 "학용품 온라인 판매점" 데이터를 사용할 거예요. 아래 데이터를 Excel이나 Google Sheet에 입력한 후 CSV 파일로 저장하세요.

    파일명: sales_data.csv

    Month,Sales,Category,Profit
Jan,2500,Pencil,500
Feb,2800,Pencil,600
Mar,2200,Pen,400
Apr,3100,Pen,700
May,2900,Eraser,450
Jun,3200,Eraser,750
Jul,3500,Pencil,800
Aug,3700,Pen,900
Sep,3400,Eraser,800
Oct,3900,Pencil,1000

    ✅ 체크포인트: 파일이 저장되었다면, 파일 탐색기에서 바로 열어볼 수 있어야 해요!

    Step 1: 오렌지3 켜고 워크플로우 캔버스 준비하기¶

    1. 오렌지3 아이콘을 더블클릭해서 열어요
    2. 빈 워크플로우가 나타나면 준비 완료! (혹시 최근 파일이 열리면 File → New 클릭)

    💡 팁: 오렌지3가 안 깔려 있다면 공식 사이트에서 무료로 다운로드할 수 있어요!

    Step 2: 데이터 로드하기 (File 위젯)¶

    목표: CSV 파일을 오렌지3에 불러오기

    1. 왼쪽 위젯 패널에서 "Data" 탭을 찾아요
    2. "File" 위젯을 캔버스로 끌어다 놔요 (마우스로 드래그)
    3. File 위젯을 더블클릭하면 파일 선택 창이 열려요
    4. 아까 저장한 sales_data.csv를 선택해요
    5. "Open" 버튼을 누르면 데이터가 로드돼요

    캔버스에 이런 모양이 보이면 성공입니다:

    [File] → (오른쪽에 출력 포트가 동그랗게 보임)

    ✅ 체크포인트: File 위젯의 오른쪽에 작은 동그란 "포트"가 보이나요? 그게 데이터가 나가는 출구예요!

    Step 3: Bar Plot으로 카테고리별 판매량 비교하기¶

    목표: 상품 카테고리(Pencil, Pen, Eraser)별로 총 판매량이 어떤지 비교하기

    1. 왼쪽 패널에서 "Visualize" 탭을 찾아요
    2. "Bar Plot" 위젯을 캔버스에 드래그해요
    3. File 위젯의 오른쪽 포트를 Bar Plot의 왼쪽 포트로 연결해요 (클릭하고 드래그)

    4. 연결되면 주황색 선이 나타나요!

    5. Bar Plot을 더블클릭해서 설정 창을 열어요

    6. 설정 창에서:
    7. X axis: "Category" 선택
    8. Y axis: "Sales" 선택

    9. Aggregation: "Sum" (합계를 구하기 위해)

    10. Apply 버튼을 누르면... 🎉

    멋진 막대 그래프가 나타나요!

    ✅ 체크포인트: 그래프에 Pencil, Pen, Eraser 세 개의 막대가 보이나요? 각 막대의 높이가 다르다면 성공입니다!

    Step 4: Line Plot으로 월별 판매 추이 보기¶

    목표: 시간이 지남에 따라 판매량이 어떻게 변했는지 선 그래프로 표현하기

    1. "Line Plot" 위젯을 캔버스에 추가해요
    2. File 위젯의 포트를 Line Plot으로 연결해요
    3. Line Plot을 더블클릭해서:
    4. X axis: "Month" 선택

    5. Y axis: "Sales" 선택

    6. Apply 누르면...

    1월부터 10월까지 판매 추이가 선으로 쭉 이어져요! 📈

    💡 보이는 패턴: 그래프를 보니 어떤 느낌이 드나요?

    아마 대체로 오른쪽 위로 향하는 선이 보일 거예요. 이건 "시간이 지날수록 판매가 증가한다"는 의미입니다!

    Step 5: Scatter Plot으로 판매량과 이익의 상관관계 찾기¶

    목표: 판매량이 높을수록 이익도 높은지 알아보기

    1. "Scatter Plot" 위젯을 캔버스에 추가해요
    2. File 위젯을 Scatter Plot으로 연결해요
    3. Scatter Plot을 더블클릭해서:
    4. X axis: "Sales" 선택

    5. Y axis: "Profit" 선택

    6. Apply 누르면...

    점들이 우상향으로 흩어진 모양이 보여요! 📍

    이건 "판매량이 많을수록 이익도 크다"는 양의 상관관계를 보여줍니다.

    ✅ 체크포인트: 왼쪽 아래에서 오른쪽 위로 향하는 대각선 방향으로 점들이 모여 있나요?

    Step 6: 결과 확인 및 해석하기¶

    워크플로우 전체 모습:

    [File] ──→ [Bar Plot]
       ├→ [Line Plot]
       └→ [Scatter Plot]

    이제 세 개의 그래프가 모두 같은 데이터를 다르게 보여주고 있어요!

    각 그래프가 말하는 이야기:

    • Bar Plot: "Pencil이 가장 많이 팔렸어요"
    • Line Plot: "시간이 지날수록 판매가 늘어나는 추세예요"
    • Scatter Plot: "판매가 많을수록 이익도 함께 늘어나요"

    💡 깨달음: 같은 데이터도 표현 방식에 따라 전혀 다른 이야기가 되죠!

    📝 전체 코드¶

    오렌지3는 GUI(그래픽 인터페이스)로 작동하기 때문에 "코드"라는 게 없어요. 하지만 같은 작업을 파이썬으로 하려면 이런 라이브러리들을 쓰게 됩니다:

    import pandas as pd
import matplotlib.pyplot as plt

# 데이터 로드
df = pd.read_csv('sales_data.csv')

# 1. Bar Plot (카테고리별 판매량 합계)
category_sales = df.groupby('Category')['Sales'].sum()
plt.figure(figsize=(8, 5))
category_sales.plot(kind='bar')
plt.title('Category별 총 판매량')
plt.ylabel('판매량')
plt.show()

# 2. Line Plot (월별 판매 추이)
plt.figure(figsize=(10, 5))
plt.plot(df['Month'], df['Sales'], marker='o')
plt.title('월별 판매 추이')
plt.xlabel('월')
plt.ylabel('판매량')
plt.show()

# 3. Scatter Plot (판매량 vs 이익)
plt.figure(figsize=(8, 5))
plt.scatter(df['Sales'], df['Profit'])
plt.title('판매량 vs 이익')
plt.xlabel('판매량')
plt.ylabel('이익')
plt.show()

    📌 참고: 위 코드는 "이런 식으로도 만들 수 있다"는 걸 보여주는 거예요. 오렌지3로는 이 모든 걸 클릭만으로 했어요!

    ⚠️ 자주 하는 실수¶

    실수 1: "File 위젯과 그래프 위젯을 연결 안 함"¶

    증상: 그래프가 비어 있거나, "데이터가 없습니다"라는 메시지가 나와요.

    왜 이런 일이? 위젯들은 선으로 연결해야 데이터가 흘러가요. 연결 없으면 고아(?) 위젯이 되는 거죠. 😅

    해결법: - File 위젯의 오른쪽 동그란 포트를 클릭하고 - 그래프 위젯의 왼쪽 포트로 드래그해요 - 주황색 선이 나타나면 성공!

    실수 2: "X축이나 Y축을 제대로 선택 안 함"¶

    증상: 그래프는 나타나지만 의미가 이상해요. (예: 숫자 대신 단어들만 늘어서거나)

    왜 이런 일이? Bar Plot인데 X축에 숫자 데이터를 선택하거나, Line Plot인데 순서가 없는 데이터를 선택했을 거예요.

    해결법: - Bar Plot: X축 = 카테고리(문자), Y축 = 수치 - Line Plot: X축 = 시간순서(월, 날짜), Y축 = 수치 - Scatter Plot: X축과 Y축 모두 = 수치 데이터

    실수 3: "Aggregation(집계) 설정을 빼먹음"¶

    증상: Bar Plot에서 막대가 너무 많거나 이상하게 보여요.

    왜 이런 일이? 같은 카테고리가 여러 줄에 있으면, 설정하지 않으면 각 줄을 따로따로 막대로 만들어요.

    해결법: Bar Plot 설정에서 Aggregation을 "Sum"으로 꼭 설정하세요!

    1차시 마무리 — 나도 데이터과학자! 미니 프로젝트¶

    🎯 이 장의 학습 목표¶

    • 오렌지3에서 데이터 불러오기 → 시각화 → 분석의 전체 흐름을 혼자서 구성할 수 있다
    • 1차시에서 배운 핵심 내용을 종합 정리할 수 있다
    • 예상 학습 시간: 약 10분

    📚 미리 알아야 할 것¶

    • 오렌지3에서 위젯을 꺼내고 연결하는 방법 (이전 장에서 배웠어요!)
    • File, Data Table, Distributions 위젯의 기본 사용법

    📚 핵심 개념¶

    개념: 데이터 분석 파이프라인¶

    1. 비유로 시작: "파이프라인은 마치 요리 순서와 같아요. 재료 준비(데이터 불러오기) → 조리(시각화·분석) → 완성(결과 확인)까지 일련의 흐름이죠."
    2. 정확한 정의: 데이터를 입력받아 처리하고, 결과를 출력하기까지의 연결된 작업 흐름 전체를 파이프라인이라고 합니다.
    3. 예시로 확인: 오렌지3에서 위젯을 선으로 연결한 워크플로우가 바로 여러분의 파이프라인이에요!

    🔨 따라하기: 미니 프로젝트¶

    Step 1: 나만의 워크플로우 완성하기¶

    오렌지3를 열고, 아래 순서대로 위젯을 배치하고 연결하세요.

    1. File 위젯 → 샘플 데이터 중 iris를 선택합니다
    2. File → Data Table 연결 → 데이터가 잘 들어왔는지 확인
    3. File → Distributions 연결 → 변수 하나를 골라 분포를 확인
    4. File → Scatter Plot 연결 → 두 변수의 관계를 점 그래프로 탐색
    graph LR A[📂 File] --> B[📋 Data Table] A --> C[📊 Distributions] A --> D[🔵 Scatter Plot]

    ✅ 체크포인트: 위젯 4개가 연결되고, 각 위젯을 더블클릭하면 결과가 보여야 해요!

    Step 2: 나의 첫 분석 결과물 저장하기¶

    완성된 워크플로우 화면을 캡처해서 저장하세요. 이것이 여러분의 첫 데이터 분석 포트폴리오입니다! 🎉

    💡 잠깐! Scatter Plot에서 점의 색상이 품종별로 다르게 나뉘는 것이 보이나요? 그게 바로 데이터 속 패턴이에요. 여러분은 방금 데이터과학의 핵심을 경험한 거예요!

    ⚠️ 주의할 점¶

    • 위젯 연결이 안 될 때: 위젯의 출력 포트에서 드래그를 시작해 다음 위젯의 입력 포트에 놓아야 해요
    • 데이터가 안 보일 때: File 위젯을 더블클릭해서 데이터가 제대로 선택되었는지 확인하세요

    ✅ 점검하기¶

    1. 데이터 분석 파이프라인의 세 단계는 무엇인가요?
    정답 확인데이터 불러오기 → 시각화 → 분석(결과 확인)
    1. 오렌지3에서 위젯끼리 연결한 전체 흐름을 무엇이라고 부르나요?
    정답 확인워크플로우(파이프라인)
    1. Scatter Plot에서 점의 색상이 나뉘는 이유는?
    정답 확인데이터 속 서로 다른 그룹(범주)이 존재하기 때문이에요

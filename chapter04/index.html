    여기까지 정리! — 데이터과학 감 잡기 미니 퀴즈¶

    🎯 이 장의 학습 목표¶

    • 1~3장 핵심 개념을 퀴즈로 복습할 수 있다
    • 내 이해도를 스스로 점검할 수 있다
    • 예상 학습 시간: 약 5분

    📚 미리 알아야 할 것¶

    • 1장: 데이터과학이 뭔지
    • 2장: 데이터과학이 쓰이는 곳
    • 3장: 데이터과학의 작업 흐름

    📝 미니 퀴즈 — OX로 풀어봐요!¶

    아래 문장이 맞으면 O, 틀리면 X를 떠올려 보세요.

    Q1. 데이터과학은 데이터에서 유용한 정보를 뽑아내는 과정이다.

    정답 확인⭕ 맞아요! 데이터를 수집→분석→활용하는 전체 과정이에요. (👉 1장 복습)

    Q2. 데이터과학은 IT 회사에서만 사용한다.

    정답 확인❌ 아니에요! 의료, 스포츠, 농업 등 거의 모든 분야에서 활용돼요. (👉 2장 복습)

    Q3. 데이터과학의 첫 단계는 바로 분석하기이다.

    정답 확인❌ 틀려요! 먼저 **데이터 수집**이 첫 단계예요. (👉 3장 복습)

    🔨 따라하기 — 빈칸 채우기¶

    데이터과학의 흐름을 떠올리며 빈칸을 채워보세요.

    수집 → ____ → 분석 → ____

    정답 확인 **수집** → **정리(전처리)** → **분석** → **활용(시각화·의사결정)**

    💡 잠깐! 3문제 중 2개 이상 맞혔다면 기본 개념이 잘 잡힌 거예요! 👏
